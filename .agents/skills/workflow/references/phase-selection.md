# Compose only the required work

Select phases from the requested outcome, current scope, consequential risks, and valid evidence.
Judge consequences and unresolved boundaries; line count alone does not establish low impact.
A configured graph is a role catalogue; activate only the work this run requires.
Read the selected method for its exact obligations. Keep method-required independence and counts.

## Select before dispatch

For each material candidate phase, choose one disposition:

| Disposition    | Condition                                    | Action                                 |
|----------------|----------------------------------------------|----------------------------------------|
| Needed         | A relevant obligation is unresolved          | Run its owning method                  |
| Reused         | Current evidence already satisfies it        | Cite the evidence; omit duplicate work |
| Combined       | Compatible duties fit one substantive owner  | Reuse worker; preserve independence    |
| Not applicable | Its trigger is absent or beyond the endpoint | Omit phase and workers                 |
| Blocked        | Required prerequisite or authority is absent | Resolve within scope or report the gap |

Combine compatible work when one capable worker can do it. Keep required independent judgment
separate.
Reused evidence must cover the claim, revision, dependencies, workload, and conditions that matter.
Apply the owning method's evidence-validity rules, including any justified carry-forward after
rebase.
A worker's confidence or a planned check is not evidence. A stale recipe or changed head can make
only part of a phase needed again. Preserve unaffected findings; rerun affected gates.
An unknown trigger stays conditional until investigation settles it. It is not yet not applicable.
Record material selections in the existing checklist or owning Task; routine actions need no ledger.

Helpers stay with the assigned agent; a workflow does not require one agent per linked method.
This map does not authorize skipping a method's required steps after its trigger applies.

An explicit request still requires its result; a convenient shortcut cannot erase it.
For refactoring, preserve behavioral equivalence. For bug repair, prove the original failing path.
For performance claims, retain comparable measurement and correctness evidence.
For consequential design or delivery, preserve the required independent verdict.
Missing UI baselines, authentication, live surfaces, or review capability block those claims;
they do not make the claim irrelevant or passed. A substituted surface narrows the evidence only.

## Size the active team

Select roles after phase selection; count only selected identities and declared nested workers.
A narrow explanation needs no exploration panel. A helper invocation needs no separate agent.
A cheap deterministic check can run with its author; the assigned checker assesses its receipt.
The coordinator checks gate identity/status, not substantive evidence.
Add a dedicated verifier for substantial surface coverage, judgment, or consequential risk.
Keep a separate reviewer when independence is required or requested.
Assign a specialist lead for bounded synthesis/integration; do not call it a pipeline coordinator.
A single writer may handle a coherent feature; parallelize independent artifacts or write scopes.

State explicit role reuse; do not call an author's check independent review.
Preserve persistent design coworkers across a coherent iteration when current context is useful.
Use a fresh worker for unrelated scope, stale directives, or an evidenced failed approach.
Carry consolidated constraints into every replacement; do not continue an interrupt chain blindly.

When removing a lead, explicitly route children and returned evidence to the remaining owner.
When removing a phase, relay valid upstream artifacts to consumers and remove obsolete waits.
Recompute counts and limits before dispatch. Reevaluate selection after scope, evidence, or the
requested endpoint changes. Stop at the actual completion condition, not the largest graph template.
