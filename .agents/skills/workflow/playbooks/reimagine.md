# Reimagine

Use to discover stronger approaches before committing to a direction. Use the `coordination-policy`
skill for dispatch and bounded work.

1. Give four independent agents the same goal, current approach, constraints, available evidence,
   and a share of one total time/resource budget. Preserve existing commitments;
   distinguish proposals from decisions.
   Require each agent to use the internet for deep research within its concern. Follow promising
   sources beyond search summaries; read primary documentation, papers, measurements, and case
   studies where relevant. Compare methods and conditions, check consequential claims, and cite
   sources supporting recommendations. If internet access is unavailable, report the research gap.
2. Assign one concern to each agent:
   - **Speed:** speedup (Use the `speedup` skill); baseline, references, and stretch
     target.
   - **Altitude:** altitude (Use the `altitude` skill); purpose and alternative
     approaches.
   - **Depth:** deepen (Use the `deepen` skill); stronger methods, evidence, and
     rewritten brief.
   - **Range:** range (Use the `range` skill); techniques from other fields and
     applicability checks.
   Isolate benchmark scratch files and shared runtimes. Report unavailable capabilities explicitly.
   Each agent may report no useful opportunity; do not invent one to fill its concern.
3. Read all four results. Check consequential claims against evidence; resolve factual conflicts
   within budget. Remove duplicate proposals and expose incompatible assumptions.
   For consequential recommendations, explain why the evidence applies to this project and which
   differences in workload, environment, or constraints limit that transfer.
   Identify incomplete or failed investigations and their effect on the recommendation.
4. Synthesize the four investigations. Remove duplicates, explain the value and cost of each
   distinct opportunity, and recommend what to pursue. Include evidence, uncertainty, and
   verification approaches. Keep measured facts separate from research and hypotheses.
   Return objective and value choices to the user. Do not adopt proposals or start implementation.

**Reply:** opportunities, recommendation, evidence links, and choices requiring user judgment.
