# Altitude

> What's the goal beyond the goal?

1. Identify the requested deliverable, intended consumer, and outcome it should enable.
   Separate stated intent from your assumptions about what the user values.
2. Keep binding constraints. Question whether the current approach is necessary for that outcome.
3. Propose at most three distinct approaches, including the original when viable.
   State benefits, costs, required access, and how each outcome could be verified.

Return the alternatives and a recommendation against the user's stated criteria.
Leave unresolved value choices with the user. Do not change the goal or start implementation.
