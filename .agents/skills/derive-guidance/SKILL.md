# Derive guidance from learning

Find what was missing in our thinking. Build the mental model that explains it.
Propose the principle or procedure that makes the improved thinking reusable.

## 1. Find the gap

Read the learning, evidence, attempted approach, and correction.
Name the mistaken assumption or missing relationship that led to the failure.
Check existing guidance: was understanding missing, or was a clear instruction not followed?

## 2. Build the mental model

Explain how the relevant parts relate and why the old approach failed.
State what the model changes about the next decision. Preserve its conditions and exceptions.
Check it against the original failure and a different case; expose unsupported generalizations.

## 3. Choose the guidance

Propose a principle for reusable judgment, or a procedure for a repeatable sequence with a result.
Build on existing principles. Link existing procedures where relevant.
Propose changes to those principles or procedures when the learning exposes a gap.
Improve an existing owner when it already covers the model. Resolve conflicting rules explicitly.
Use the `keep-intent-aligned` skill and encode-lessons-in-structure (Use the
`encode-lessons-in-structure` skill) to shape its prescriptions.
Preserve human intent and Plan/Spec/Task ownership.
Prefer structural enforcement for recurring rules; keep prose for judgment.
If existing guidance was sufficient, explain the application failure instead of adding another rule.

## 4. State the proposal

Make the prescription explicit, simple and short.
For procedures, name inputs, permitted writes, output locations, actions, and completion criteria.
Resolve paths and commands from project files. Report missing prerequisites; do not invent them.
Return the thinking gap, corrected mental model, supporting evidence, and proposed guidance.
Name its owner and trigger. Keep the proposal distinct from an accepted rule.
