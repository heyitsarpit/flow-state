# Round 11: where the fixture front end differs from the public API

Status: **proposed**, for the compile prototypes (HANDOFF step 3) and Arpit's read. `conformance/typed/flow.ts` is the **fixture front end**, not the compiler (review L4): what the suite boots is compiled by it, and where it bends the design that is listed here, with before and after. Each row is one of three kinds:

- **Design**: the design's spelling, adopted this round where the front end had another.
- **Deviation**: the thin path's own spelling, kept, with the reason and what would retire it.
- **Seam**: not public API at all. A hand fixture drives the runtime below the API; the seam keeps that case on typed output and is counted apart (RESULTS, "Seams").

| Thing | Kind | Before (round 10 or this round's first spelling) | After | Why |
| --- | --- | --- | --- | --- |
| `unknown` by reason | Design (review M5) | `unknown: { byReason: { NoResponse: E.Unsure } }` (D201's first form: `Compiled`'s word leaked) | `unknown: { NoResponse: E.Unsure, Cancelled: E.Stopped }`, a record by reason, as `failure` is by tag (design C6); one token still means one event | The compiled form stays `byReason`; the definition does not say it |
| An optional key | Design (review M5) | `last: Flow.absent(Schema.Unknown)` | `last: Schema.optionalKey(Schema.Unknown)`, the bare Schema as the field (2.2.2) | "an optional key starts absent", with no `Flow` marker. A decoding default on it (`withDecodingDefaultKey`) applies at restore only (Lab/MemoryRelease) |
| History as an object's target | Fix (review H3) | `{ target: S.A.history, updateMemory }` compiled as a plain transition | the same `history: true` as the bare `S.A.history` | One decision, `=== true`, for both forms; pinned in `checks/front-check.ts` |
| A guard closure's path | Fix (review M1, D206) | `guard[n]` counted among closures, a token's key by place: two Slots could share a path | every element by its place in the array | A path names one Slot; the seal now refuses two (`SealDuplicatePath`, D207) |
| A selector's event | Fix (review H1) | `<Ev>` free, so `event` was `unknown` with no default and the body's inference broke | `<Ev = { [k]: unknown }>`: a handle's selector reads the event's fields as `unknown`; an annotated selector is typed by its annotation | A handle is made once for the body and cannot know which event it sits under. To type it by its handler would need the handle made per event: a compile-prototype question |
| An exit behind a guard | Deviation, small | an exit token took no guard | `{ guard: [...], exit: exits.Done.from(f).exit }` | AddressStep's `Confirm` (F6). The design writes `target: exits.Done` in an alternative; the thin path's alternatives have no exit target, so `exit` is a field |
| A subroutine's instance name | Deviation | always its state's name | `into: { fragment, name }`; default the state's | The hand Desk/Ticket names RESOLVING's wizard `wizard` and its cases address `["wizard"]`. Retire with that fixture |
| Placement | Deviation (inherited from round 10) | placement and filling together in the machine body (`traits: { x: { fragment: F, ...fill } }`, `into:`), and `places` on the definition for `E.x.Event` raises | unchanged | The design places in the definition (2.3: "placement is structure") and fills in the machine. The compiled output is the same; with placement in the body, `S` and `E` cannot see an instance's events without `places`. For the compile prototypes |
| A read's function | Deviation (inherited) | `resource({ commit })` | unchanged | The design calls it `lookup`. A rename |
| `unknown:` targets | Deviation (inherited) | any event | unchanged | The design allows only `Flow.uncertain` events. Not checked by this front end |
| `index` on an alternative | Seam | sets a Slot's path to the hand-flattened Pay's index (`[1]` where the real machine's `[0]` was flattened away) | unchanged, in typed Pay and pay-full | `--swap` boots the pinned hand Pay under the same scenarios, whose fault addresses (`states.PAYING.on.Confirmed[1].guard[0]`) name the hand paths. Removing it means changing those addresses, and `--swap` then misses them on the hand Pay. Retire with the pinned Pay |
| `labFollowUps` | Seam (D203) | hand `followUps` | `labFollowUps: [(a) => ({ tag, payload })]` | A head insertion of the machine's own event, which the design leaves to the runtime (rule 54). Ring, Notes' `SetDocsThen`, Kept's `LookBoom`, the serial Bare's `Two` (F4) |
| `labHostOp(op)` | Seam (D212, review M5) | a literal `{ opGuard: { op: "job", verb: "idle" } }` and `{ member: "cancel", op: "job" }` in typed fixtures | `labHostOp("job").idle`, `labHostOp("job").cancel` | A host acting on its fragment's operation, which rule 50 forbids. Edge's `IfJob`, pay-full's shipping guard, Let's `Forget` (F3). The fixtures are wrong by the design |
| `moduleMember(op, module, name, f?)` | Deviation (D208) | hand `{ verb: "module" }` members | a function that makes the member | The design's `O.x.bookmark`, `O.x.refetch` are handles of the sessions module, which has no typed front end here |
| `activities: [{ op, input, when? }]` | Deviation (D208) | hand `activities` | the same shape, in a state's or a trait's body | The design's `O.x.subscribe(select)` in `activities`; no stream handles here |
| `domain`, `streams` | Deviation (D209) | hand blocks with bare closures | `definition({ domain, streams: ({ E }) => ... })` in `Compiled`'s own shape, every closure a Slot under its own path | The design's entity API (2.8) and stream contract (2.11) have no front end here; that is HANDOFF steps 3 and 4. This shows `Compiled` carries them as Slots, not that the design compiles to them (F5) |
| Services | Runtime contract (D211) | `provide(typed, context)` wrapped every commit in `Effect.provide` | `Fixture.services(api)`, given to the Runtime at boot; fibers run with them at their root | `Effect.provide` per commit is a step a seeded scheduler sees (F10); production gives the Runtime a Layer once |
