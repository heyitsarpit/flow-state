# Behavior Contract

This page describes the application behavior contract commands exposed by the
installed package.

It is intentionally terse and shared between humans and AI agents. Treat it as
the shortest app-level onboarding and planning surface for the current behavior
contract loop: `flow-state behavior build`, `flow-state behavior render`, and
`flow-state behavior diff`.

Use `flow-state behavior build` to emit a contract, `flow-state behavior render`
to inspect it, and `flow-state behavior diff` to compare revisions. Continue with
[Current Status](/reference/status) for the supported runtime surface.
