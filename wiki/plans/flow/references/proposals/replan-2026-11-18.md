## 1. Decision record: `module-composer` not adopted

Decided by the user (2026-11-18): the package's value is dubious; Flow uses Effect Schema, small Flow-side wrappers
and lint. What it offered, and what replaces each (replacements **proposed**):

- **`Layer(name, enter)`, the one way in, with its catch-all** → `entry(name, run)` in Flow, about 15 lines: the
  arguments decode by Schema, any non-FlowError throw becomes a FlowError `Defect` with the cause (section 2).
- **`Checked<typeof X>` brands on a layer's output** → `Schema.brand` on decoded types (`DecodedConfig`,
  `ActorName`, `RecordKey`, ...). Effect's brand is type-only, so it costs nothing at run time.
- **`X.is` for unforgeable object layers** → a module-private `WeakSet` of what Flow made, one per definition for its
  tokens. Effect's `Redacted` is the precedent.
- **`Raw<"source">` parameters** → `unknown` at each entry point; internals take branded types only.
- **Composition proofs (type-level ring files)** → the boundary map page (section 4), the existing import rules in
  code:tools/lint-bomb/FLOW-STATE.md ("Scope"), and the surface test. No type-level proof files.
- **`LayerError`** → the existing `FlowError` and `Diagnostic`; no new fields (the boundaries proposal's `door`,
  `origin` and `site` are not carried over).

Prior art kept for a return: `/Users/arpit/Developer/workflow/module-composer` and its `REVIEW-opus.md`, logged in
`revisit.md`. Superseded here: `boundaries-2026-11-18.md` and `layers-checked-2026-11-18.md`.

## 2. The boundary Task (new, proposed): public entry points refuse only with a FlowError

```text
    title       Every public entry point refuses with a FlowError; a surface test finds any that doesn't
    status      draft
    priority    high
    derives_from @spec.Diagnostics (R1, R3, I5), @spec.Codec (R6)
    description
        Every public function Flow exports or hands out either refuses with a FlowError or is an inert builder, and a
        test proves it without a hand-kept list.

        **Why now:** T81's last three blockers and the routed raw throws (`app`, `runtimeSetup`, `actorRef`,
        `createActor`, `ensureActor`, `disposeActor`, `resource`, `transaction`, `send` with a throwing getter) are one
        class: no public function has a catch-all, so anything a check missed escapes as a raw TypeError. The
        corruption sweep (`tests/compile/corruption.test.ts`) lists its slots by hand, which is how blockers 1 and 2
        were missed.

        **Read first:** code:packages/flow-state-v3/src/core/boundary.ts#walkerOf,
        code:packages/flow-state-v3/tests/compile/corruption.test.ts, @spec.Diagnostics,
        code:wiki/conventions/boundaries.md (written by this Task from the replan's section 4).

        **Approach:** `src/entry.ts` exports `entry(name, run)` for sync calls and `entryEffect(name, run)` for
        Effect-returning ones (`ready`, `dispose`), whose refusal is `Effect.fail` (Diagnostics R1). Each wraps `run`
        in `Result.try`; a FlowError passes through, anything else is `Defect` at `name` with the cause. Every public
        function goes through one, or is registered as a builder. The surface test builds every fixture app's
        definitions, machines, app, Runtime and one actor, walks every function-valued property reachable from them
        and from `src/index.ts`, and requires each to be a registered entry or builder, naming the path of any
        other. A hostile-value table (null, undefined, NaN, ±Infinity, a Date, a Map, a function, a cycle, a
        throwing getter, a Proxy that throws on every trap, a copied token) runs at every argument position of every
        entry; each call returns or throws a FlowError, under a 1 s bound.

        May change: `src/`, `tests/`, `tools/lint-bomb/FLOW-STATE.md`, `vite.config.ts` (lint), `wiki/conventions/`,
        @spec.Diagnostics with a `specs.log` note. Evidence: this Task's comments.

        False pass: an entry point the walk can't reach (a function only a callback receives) → caught by the walk
        also visiting the arguments Flow passes to body and operations callbacks (`S`, `E`, `O`).
        Gates: `nub run faults`, with planted faults `entry-unwrapped` (one export loses its wrapper) and
        `stray-throw-raw` (the wrapper rethrows the cause), each caught by the surface test.
        User's read: the list of functions registered as builders, and any entry point given a new refusal code.
    acceptance
        - The surface test passes on every fixture app, and fails naming the path when one export's wrapper is
          removed.
        - Every hostile value at every argument position of every entry gives a FlowError or a normal return; no
          raw error and no hang.
        - Lint: `hasProperty(_, "~` is banned in `src/`; `throw` outside `src/error.ts` and `src/entry.ts` is
          flagged; each remaining disable carries its reason.
        - `wiki/conventions/boundaries.md` exists, linked from the conventions README, and every row names its owner.
        - `nub run check`, the suite, stress and `nub run faults` pass.
```

## 4. Flow's boundary map (proposed page: `wiki/conventions/boundaries.md`)

The page lists every source of untrusted input, where it becomes trusted, and its owner. Proposed content:

```markdown
# Boundaries

Untrusted input becomes trusted in exactly one place per source, by one complete Schema decode; after that,
internals take only the decoded, branded value and never check it again. A public function either decodes its
arguments (an entry) or stores them unread (a builder). Anything else that throws is a FlowError Defect.

| Source                         | Where it is checked                                         | Owner          |
| ------------------------------ | ----------------------------------------------------------- | -------------- |
| Construction config            | `definition`, `machine`: one Schema each, via the walker     | T81            |
| Builder arguments              | captured unread; checked by the `definition`/`machine` decode| T81            |
| Flow-made values (tokens)      | `WeakSet` membership, per definition for its tokens          | T81            |
| App and Runtime setup          | `app`, `runtimeSetup`: Schema decode in `entry`              | boundary Task  |
| Event payloads                 | `send`, `E.X`, Story steps: the event's compiled check      | built (T81)    |
| Refs and actor calls           | `ensureActor`, `createActor`, `disposeActor`: ref decode     | boundary Task  |
| Runtime options                | `ready`, `dispose`: `entryEffect`                            | boundary Task  |
| Any stray throw in an entry    | `entry` / `entryEffect`: FlowError Defect with the cause     | boundary Task  |
| User callback results          | one callback wrapper; patch keys and values by field Schema  | new Task (P4)  |
| Server answers                 | only through the user's mapper, then the event's check       | new Task (P4)  |
| Saved records at boot          | one Schema per record kind, from Compiled; branded ids      | T92            |
| Records across releases        | version and fingerprint stamps                               | T56            |
| Real storage (IndexedDB)       | the host adapter's read, then T92's Schemas                  | T28, T58       |
| CLI-loaded config              | the same entries as construction                             | T22            |

Not checkable, by contract: a callback that never returns; a forged Effect Schema (its parser's throw is caught);
a service's answer before its mapper. Brands: `ActorName`, `RecordKey`, `LaneKey`, `AttemptId`, `StateName`.
Lint and the surface test enforce the page; a new source changes this page first, then the code.
```

Gap found while drafting: a user callback's result enters the turn unchecked. `updateMemory`'s patch is spread
outside its `call` (code:packages/flow-state-v3/src/core/turn.ts#accept), and an ending mapper's payload is not
checked against its event (`src/core/serve.ts`, the mapper comments at 242 and 255). Proposed owner: a new small P4
