## Findings (none blocking)

- **M1, a signature can't separate roots, so the soak can hide a new class.** In pay-varied-11 with its
  lane-queue rows unexcused, the first break is unbound-rooted (`place att-11000-12 (Held) got Send` after the
  step-51 restore). Its signature, `lane-queue WriteLanes I12`, is the one `TRIAGED_SIGNATURES` calls retry.
  Shrinking it by signature slid to a different root. The 13-step result has no dispose and breaks on
  `Await Released of att-11000-15 … not met`, which is the retry pattern.
  - So any new bug whose first break is one of the four keys prints `KNOWN (<root>)`. Nothing is shrunk, nothing
    is kept, and the soak exits 0 (`runner/soak.ts#soak`, `parts/soak.ts#soaked`).
  - The soak's "shrinks each new failure" holds per signature only.
  - Proposed: add the refusal's structured cell to the signature (the Attempt's phase and the refused move, e.g.
    `Held/Send` against `Released/TurnCloses`), and shrink only while that whole key holds.
- **M2, the shrinker isn't 1-minimal.** `shrunkPart` makes one forward pass per chunk size and never retries an
  earlier position after a later removal (`parts/shrink.ts#shrunkPart`). The doc's "until no single step can go"
  is false: PART-transfers-varied-2001-shrunk still has three removable Sends. Leading ensures are never tried.
  - Proposed: repeat the size-1 pass until nothing changes, and either try leading ensures or say they are kept.
  - Pin it with a test that removes each step of a shrunk case.
- **M3, the owner test passes with a wrong owner.** `varied.test.ts`, "every varied red is triaged", asserts
  `some` row of the first signature has the triaged root.
  - Plant: flip only pay-varied-11's `disposal Actors I29` row to retry. The test stays green, and it is red only
    on the one-part plant (pay-varied-103 to unbound).
  - It matches rows with `signature.includes`, so `WriteLanes I1` matches `I12`. That is latent in four scripts.
  - Rows outside the first signature are never checked.
  - Proposed: require every row of the first signature to carry the root, match exact `check invariant` pairs,
    and pin later rows by their traced first break.
- **m1, mixed roots on one row.** MIX+pay-stress-1's `att-1001-13` never meets a dispose of acct-2: it is
  re-sent across boots, so it roots in retry. It still sits on that script's unbound I15 and I29 rows (T54),
  because a script, check and Invariant hold one row. T54's close would trip on it. That is N1's residue.
  Proposed: a root per item, not per row.
- **m2, the timer test** (check 5): assert on a generated varied script's `advance` against its deadline.
- **m3, the soak's edges.**
  - `--count` that isn't a number, or is 0, passes with 0 scripts.
  - The default output is `.`.
  - A target that doesn't reproduce is written unshrunk under `-shrunk` (`shrunkPart`, the `isNone` branch).
  - The unbroken and thin checks aren't run.
  - The base reach counts failing gate runs.
- **m4, rewrites that erase a loss.** `pairs-record` writes the record whatever the verdict, so the next `pairs`
  run passes after a loss. `writeMatrix` already does the same.
  - The pairs gate takes 3 s but isn't in `checkpoint`, so `verify` never reads `cell-pairs.production.txt`.
  - A missing record passes silently.
- **m5, small code points.**
  - `VariedRoot` repeats `Root`'s literals. Use `typeof Root.Type`.
  - `signatureOf`'s `Pass` branch never runs.
- **m6, labels.** The P4.task comment at 14:26:48Z and the edit appended to the 14:36:48Z review comment carry no
  Reverse.
