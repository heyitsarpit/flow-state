**Verdict: one finding blocks, in T61. T52 goes on.** The trace mode crashes on every case id that holds a `/`, so
T61's trace item is broken for variant cases (B1, small fix). Every other claim in both ranges holds on a clean copy:
the adversary and the field gate refuse each plant, the three hand-edited sweep rows match a real sweep exactly,
coverage standings are identical, all 59 owed rows survive the move, `verify` fails on a red checkpoint gate, and the

## Blocking

**B1, the trace mode crashes on ids with `/` (T61, acceptance item "a trace file shows each step").**
`trace --case PAY-13/hung-commit --runtime production` exits 1 with `ENOENT … trace-PAY-13/hung-commit.txt`:
code:packages/flow-state-v3/conformance/runner/trace.ts writes `trace-${id}.txt` and creates only the scratch
directory. Variant ids (`PAY-06/…`, `PAY-15/…`, `TURN-01/…`, `LANE-12/…`) are a large share of the cases. Red check:
the command above. Fix: one safe file name per id, with a check over a `/` id.
