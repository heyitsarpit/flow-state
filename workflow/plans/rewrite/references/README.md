# Supporting API examples

The capability contracts live in the twelve parent `.plan` files. These focused TypeScript files
illustrate their APIs. They add no separate contract or implementation.

- [Core authoring](core-api.examples.ts)
- [Data operations and persistence](data-api.examples.ts)
- [Stories, models and inspection](tools-api.examples.ts)

Examples are uncompiled and unrun. Workflow validation does not compile them. An implementation
Task must record an explicit check before any example counts as executable proof.
