# Scope inventory: ApplicationsAndActors and ReactAndHosts

Archived sources: `workflow/plans/archive/rewrite/ApplicationsAndActors.plan` (AA),
`workflow/plans/archive/rewrite/ReactAndHosts.plan` (RH), and the archived reference they link,
`workflow/plans/archive/rewrite/references/` (README, app/host.ts, app/setup.ts, app/actors.ts,
app/view.tsx). New documents: `workflow/plans/flow/FlowState.plan` (FS), `references/design/minimal-library.md`
(ML, by section number), `references/dispatch-desk/` (DD), `references/design/entity-domain.md` (ED),
`references/design/entities.md` (EN).

Scope note from the owner: SSR hydration (Next.js), lazy-loaded features and multi-tab shared
persistence are IN scope although FS D50 lists them as non-goals; Suspense integration is not needed.

Status key: KEPT, CHANGED (preserves or loses capability, stated), DROPPED-EXPLICIT, DROPPED-SILENT.
Recommendation: RESTORE (with form) or CONFIRM-DROP; "-" where KEPT or a preserving CHANGE needs nothing.
