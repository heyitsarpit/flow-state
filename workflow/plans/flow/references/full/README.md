# Full drafts of the capability plans

The long first drafts of each capability plan, before they were cut to behaviour contracts. They
restate every archived commitment the scope review chose to keep, with mechanism, bounds and test
detail. They are implementation notes, not authority: the plan with the same name in
workflow/plans/flow/ is the contract, and where the two differ the plan wins. Use a draft to look
up detail the plan defers to build time.
