## Root-cause classes

- **RC1, unanchored runtime claims:** an oracle takes a runtime report, or the lack of one, as proof.
- **RC2, phase rebuilt or mutated outside one transition:** a phase is rebuilt from the absence of a value, or
  state is changed in place.
- **RC3, lane identity:** an Attempt's lane is named from data the Port does not always carry.
- **RC4, record and doc drift:** a doc, record or log says something other than what the code does.

## High

**H1. A quiet `Released` on a may-cancel turn passes every oracle (RC1).** This is the T6 completion review's H1
scenario, still uncaught.

- **Where:** `write-lanes/lane-queue.ts:196-202`. Any `Turn` of the owner, anywhere in the step, on an event in
  `cancels` or `mayCancel` anchors any `Released` of that operation. Pay's `mayCancel` is `IntentRead` and
  `OrderSeen` (`fixtures/pay.ts:74`), and `UNSURE` reads the intent every 3 s.
- **Rule:** WriteLanes I12 ("A Held lane leaves Held only by a retry's resolution, a cancel or cancelAll, or a
  release on leave") and R8 ("no quiet release"). Conformance R11 also applies: the old suite's lie was ported weaker.
- **Probe (run):** in a copy of round-14, a turn of `IntentRead` releases a Held `pay` head that its handler left
  Held (`turn.ts`, before `note(tx, "turn", …)`). It fires in `PAY-15/retry-budget`: after `RetryLimit` the guard
  denies the retry, alternative 3 runs, and the head is released with no cancel. Result: `suite` 67/67, no oracle
  fires.
- **Why the registered lie misses it:** `lie.held-released-unguarded` (`write-lanes/lane-queue.mutants.ts:152-162`)
  releases every hold at the moment it is held, so no turn anchors the release. The old lie
  (`prototypes/conformance/falsify.ts:305`) released only a hold whose handler's cancel is guarded out. The port
  changed what the lie means, and the difference is not recorded.
- **Fix:** anchor a may-cancel `Released` to the turn's transition, not just its event. `Turn` carries `from` and
  `to`, so `mayCancel` becomes the transitions that run the cancel (Pay: `IntentRead` `UNSURE`→`PLACING`).
  Register the probe as `lie.release-on-guarded-read` on `PAY-15/retry-budget`, `expects: "WriteLanes I12"`.

## Medium

**M1. Keyed lanes are judged only after their first send (RC3).** H1 of the T6 completion review is only partly met.

- **Where:** the prototype adapter never reports `Minted.key` (`adapters/prototype-observations.ts:133-138`), so a
  keyed Attempt joins no lane at mint (`write-lanes/lane-model.ts:150-161`). It is named at its first `Sent`, from
  the request input (`lane-model.ts:213-242`). `lanesOf`, `bounds` and `queuedOf` (`lane-model.ts:108-117,
  401-423`) skip unnamed Attempts, and `delivered-once`'s replacement reaches only `"maybe"` for keyed operations
  (`write-lanes/delivered-once.ts:109-113, 92-104`).
- **Rule:** WriteLanes I8 ("W length is 0 under reject") and R6.
- **Probe (run):** under Pay's `reject`, a busy `pay` queues behind the head instead of declining `Rejected` (lane.ts
  `busy`). `lane-queue` is silent at the step that breaks I8. Only case expectations catch it, in 3 cases (PAY-02,
  PAY-07/late-in-a-new-PAYING, PAY-15/press-pay-while-held).
- **Latent:** `placedBySend` appends on naming, so a keyed queue loses mint order (`lane-model.ts:228-241`).
- **Fix:** report the lane's key on `Minted`. Round-14 has it at mint (`world.ts:50-55`, `byAttempt`), so the
  adapter can read it there, or the Port can require it for keyed operations, which T16's production adapter must
  meet. Then make a keyed `Minted` without a key a violation, not an unnamed Attempt.

**M2. A reload drops `Held { at }`, and a later send rejoins with no check (RC2).**

- **Where:** a reload sets `live: []` (`write-lanes/lane-queue.ts:326-330`). An Attempt rejoins only on an unknown
  `Ended` (`lane-model.ts:336-348`) or on a `Sent` when its lane has no head (`lane-model.ts:257-270`, which
  returns no violation). Round-14 revives a Held head whose ending was parked without reporting an ending
  (`prototypes/round-14/durable.ts:492-495`), so that head is in no lane after the boot. A later automatic re-send
  of it is judged by neither I12 nor I1. The same silent rejoin covers a send after a `Released` or a definite end.
- **Rule:** S2's constraint list keeps `heldAt` across a reload; WriteLanes I12 and R8 ("no automatic retry").
  STYLE: one closed phase, one transition. Phase changes here are spread over `mint`, `joined`, `sent`, `end`,
  `superseded` and `without`, with no-op branches that rebuild a phase from absence.
- **Status:** read, not run.
- **Fix:** keep each known Attempt's phase across the reload (`Held { at }` stays, `Wire` becomes `Held`), and make
  a send of an Attempt in no lane a violation. Route phase changes through one `(phase, fact)` table, as
  `actors/disposal-ledger.ts`'s `ON_SENT` does.

**M4. I15's refusal exception is not built, and the doc says it is (RC4).**

- **Where:** a delivery pays the owed ending (`write-lanes/delivered-once.ts:357`). A refusal only clears the
  pending turn (`delivered-once.ts:372-376`). The redelivery R10 requires therefore finds nothing owed and fails:
  "delivered with no ending owed (twice, or never decided)" (`delivered-once.ts:205-214`). The doc says a delivery
  may be "refused (which the runtime retries)".
- **Rule:** WriteLanes I15 ("an ending whose admission refused its turn … is delivered once more after queued mail")
  and R10.
- **Status:** latent. No case refuses an admission, and the old oracle has the same gap (base `delivered-once.ts:
  228-231`).
- **Fix:** a refusal turns the paid ending back to `Owed` for one redelivery, and a second refusal is final. Add a
  case and a mutant that never redelivers.

**M5. The oracle contract now allows in-place state (RC2).**

- **Where:** the Gotcha at `dsl/oracle.ts:130-132` says "a state may be updated in place". `ending-channels` keeps
  mutable `Set` and `Map` state (`write-lanes/ending-channels.ts:153-168, 288-293`), and `attempt-identity` does
  the same (`write-lanes/attempt-identity.ts:193-197`).
- **Rule:** S1's target, "a pure step fold"; AGENTS.md, the core is pure.
- **Context:** the builder logged this (T40 S1 review, finding 14) and fixed the doc, not the code. The S2 oracles
  are pure.
- **Fix:** make the two patched oracles pure when T7 next touches them, then drop the Gotcha.
