## Root-cause classes

- **RC-A, declared, not proven:** a standing (checked, owed, cited) rests on a list the author types, and nothing
  resolves or verifies it.
- **RC-B, defect read as a result:** a throw from the implementation is turned into an answer a case can accept
  (Conformance R9).
- **RC-C, part of an Invariant judged, all of it claimed:** the cases and mutants test one clause, and coverage
  reports the whole Invariant as checked.
- **RC2, phase spread over collections** (carried from the T7 reviews): one Attempt's lifecycle lives in several
  keyed collections.
- **RC-D, record and doc drift.**

## High

**H1. Runtime creation's refusal accepts a crash, so I15 and I16 pass on a runtime that throws (RC-B).**

- **Where:** `adapters/prototype-static.ts:328-335` (`admit` maps every throw to `Admission.Refused`) with
  `codeOf` at `:122-128` (an uncoded throw becomes `Unnamed(...)`). `compile/construction.cases.ts:111` and
  `:251-264` then read only Admitted or Refused.
- **Rule:** Conformance R9: "an implementation that throws ... is a defect", and "none without a check's pass is a
  pass". Compile R17 and T8: each malformation "is refused at creation". A TypeError is not a refusal.
- **Evidence:** `rv.seal-crashes-on-key` replaces `SealKeyField`'s throw with a property read on `undefined`;
  `rv.seal-crashes-on-bare` does the same for `SealUnknownClosure`. Both survived falsify.
- **Reach:** every refusal case to come (Diagnostics, StaticCli exit codes, Compile I3 and I13) goes through the same
  adapter shape. `construct` has the same mapping (`:323-327`). There, `found.includes(code)` happens to fail on
  `Unnamed`, but nothing says so.
- **Fix:** a refusal is only a throw that carries a code (`CODE` matched). Any other throw escapes as a defect, which
  run.ts reports as a defect. Better, give the verdict its defect variant (Q2), so R9's three kinds are typed. Keep
  `rv.seal-crashes-on-*` as mutants that must be caught as defects, or as `WrongReason`, never as a pass.

## Medium

- **Where:** `compile/construction.cases.ts:249-278`. The bare-function check tampers a Compiled after

**M4. `ending-channels` and `attempt-identity` still spread an Attempt's lifecycle over keyed collections (RC2).**
