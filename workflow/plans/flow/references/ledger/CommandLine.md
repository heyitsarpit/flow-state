## Validation and integration handoff

- `workflow check --json` reports duplicate Plan IDs against untouched archive files, including
  CommandLine and Diagnostics. Fixed assignment IDs and write scope prevent repairing the archive
  here. The CLI accepts a repository directory, not a Plan path, for `workflow check`.
- Inspection O6 currently says incomplete trace diff exits 0. CommandLine O3/O4 require exit 1,
  as mandated by this inventory's CL O3 RESTORE row and binding ruling 23. Inspection must align;
  no permission to edit Inspection was supplied. Incomplete summarize/explain still exit 0.
- Inspection trace section projections supply the current section names; CommandLine O1 adds
  explicit denials and activity-lanes views over the same production facts. CommandLine owns the
  process grammar; Inspection's illustrative --attempt/--issues spellings are not added implicitly.
